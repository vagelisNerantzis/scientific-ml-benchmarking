# Assets

`workflow.svg` is a generic, accessible diagram of the sample-aware benchmarking
workflow. It contains no dataset imagery or institutional branding.

Generate it deterministically using only the Python standard library:

```bash
python assets/generate_workflow.py
python assets/generate_workflow.py --check
```

Both the generator and SVG are version-controlled source artifacts. No private
images, spectra, institutional logos or historical figures are bundled.
